# Phase 13 Landlock Syscalls Slice

This bounded Phase 13 slice keeps `security/landlock/syscalls.zig` aligned with `security/landlock/syscalls.c` as a pure helper-first packet.

The current helper stays intentionally narrow:
  * keeps `landlock_create_ruleset()` reviewable around the ABI-version query branch, minimum attr sizing, flag validation, handled-access filtering, empty-ruleset rejection, delegated ruleset-planning, and the top-level initialization plus attr-presence wrapper checks before the anonymous-fd install boundary
  * keeps `landlock_add_rule()` reviewable around ruleset-fd presence, incoming-layer validation, delegated rule-tree search and insertion planning, and the top-level initialization plus attr-presence wrapper checks without presenting live domain mutation or syscall enforcement as shipped Zigux behavior
  * keeps the helper descriptor explicit about what is in scope today: create-ruleset planning, ABI-version query planning, add-rule planning, ruleset-fd install planning, ruleset-fd stub planning, ruleset release planning, handled-access validation, attr-size validation, flag validation, incoming-layer validation, tree-walk validation, delegated ruleset creation planning, delegated rule-tree search planning, and delegated rule insertion planning
  * keeps delegated ruleset creation, rule-tree search, and rule insertion planning explicit through `security/landlock/ruleset.zig`; keeps one ruleset-fd install planner explicit about the fixed `anon_inode_getfd()` label, `ruleset_fops` binding, `O_RDWR | O_CLOEXEC` flags, and release-on-fd-failure discipline; keeps one ruleset-fd stub planner explicit about the dummy read or write boundary and shared `-EINVAL` return; and keeps one `fop_ruleset_release()` planner explicit about the `filp->private_data` handoff, `landlock_put_ruleset()` release, and zero return without presenting live anonymous-fd installation, returned-file-descriptor ownership, or live file-buffer behavior as shipped Zigux behavior
  * keeps current repo reality explicit: `security/landlock/syscalls.zig`, this slice note, and `Documentation/zigux/phase13-landlock-syscalls-governance.md` are materialized on current `master`, while the direct survey, replay, reviewability, manifest, and shared `zigux/tests/phase13_build.zig` companions remain absent

This slice does not claim anonymous-fd creation internals, live fd ownership, live path imports, credential mutation, thread synchronization, domain merges, live syscall enforcement, or `landlock_restrict_self()` planning, and it keeps the landed create-ruleset, add-rule, ruleset release, and file-operation entrypoints strictly at planning depth.
